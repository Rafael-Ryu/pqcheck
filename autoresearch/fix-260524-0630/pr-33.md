Closes #33.

## What changed
`_expand_one_group()` accidentally referenced `data`, which is only available in `_iter_requirement_strings()`. That made every `[dependency-groups]` path crash with `NameError` and also left `[build-system].requires` unreachable for build-system-only pyprojects.

This PR moves `[build-system].requires` handling back to `_iter_requirement_strings(data)` and keeps the PEP 735 group expansion helper scoped to group data only.

## Tests
- Existing PEP 735 dependency-group tests now pass again, including transitive `include-group` and cycle coverage.
- Existing PEP 518 build-system-only and dedup tests now pass again.
