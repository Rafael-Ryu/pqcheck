Closes #34.

## What changed
`detect_python_file()` used `path.stat()` followed by `path.read_bytes()`. Both follow symlinks, so a repo could include `*.py -> /dev/zero` and make the scan block while reading.

This PR replaces that flow with fd-based capped reading:

- `os.open(path, O_RDONLY | O_NOFOLLOW | O_NONBLOCK)` rejects symlinks and avoids blocking on FIFO open.
- `os.fstat()` validates `S_ISREG` and applies the 2 MiB cap to the opened inode.
- `os.read()` is capped at `_MAX_FILE_BYTES + 1`, so growth between `fstat` and read is rejected.

This branch includes the #33 parser fix as a prerequisite so full verification passes while PR #38 is still pending. Once #38 is merged, GitHub will reduce this PR's effective diff to the detector I/O changes.

## Tests
New unit coverage rejects:

- symlink to a regular file
- symlink to `/dev/zero`
- FIFO
- directory
- file growth past the cap during read
