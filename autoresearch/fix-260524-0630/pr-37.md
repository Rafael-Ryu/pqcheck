Closes #37.

## What changed
PyCryptodome block ciphers pass modes as constants such as `AES.MODE_ECB`, not as constructor calls. The detector already had a mode catalog for AES, but nothing in the direct `Crypto.Cipher.<X>.new(...)` path used it, so findings surfaced with `mode=None`.

This PR:

- extends the PyCryptodome mode catalog to cover `AES`, `DES`, and `DES3`
- extracts the second positional mode argument or `mode=` keyword from `Crypto.Cipher.<X>.new(...)`
- resolves mode constants through `ImportResolver.resolve_attribute()`
- strengthens integration coverage so `mixed_pycryptodome.py` must emit `AES/GCM` and `DES/ECB`

This branch includes the #33 parser fix as a prerequisite so full verification passes while PR #38 is still pending.

## Tests
New unit coverage includes:

- `AES.new(..., AES.MODE_ECB)` -> `mode="ECB"`
- `DES.new(..., DES.MODE_ECB)` -> `mode="ECB"`
- `DES3.new(..., DES3.MODE_CBC)` -> `mode="CBC"`
- keyword mode form
- unresolved/non-attribute/no-mode fallbacks
